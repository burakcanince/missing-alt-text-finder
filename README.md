# Missing Alt Text Finder

A Chrome extension that scans web pages to find images without alt text, helping improve website accessibility.

## Features

- Instantly scans the current web page for images without alt text
- Separates images with no `alt` attribute from images with an empty `alt=""`
- Shows a thumbnail and the source URL for each image
- Copy a single URL or all of them, or download the list as a text file

### Setup
```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
